# Official exchange integrations

Deriv current Options API uses the public market WebSocket and REST account discovery with PAT plus App ID. Discover account_type=demo and validate the authenticated OTP URL uses exactly the documented demo authority and path before connecting. Discover contract availability, request a fresh proposal, correlate its reply, and use broker evidence for contract lifecycle. [Overview](https://developers.deriv.com/docs/intro/api-overview/) · [Trading](https://developers.deriv.com/docs/trading/) · [Workflows](https://developers.deriv.com/docs/workflows/)

Kalshi Prediction Markets uses official dedicated demo REST and WebSocket hosts, RSA-PSS headers, V2 event order mutations, and decimal fixed-point book and order values. Normalize complement bids to asks. Record accepted and executed quantities separately. [Index](https://docs.kalshi.com/llms.txt) · [Environment](https://docs.kalshi.com/getting_started/api_environments.md) · [Demo](https://docs.kalshi.com/getting_started/demo_env.md) · [Signing](https://docs.kalshi.com/getting_started/quick_start_authenticated_requests.md) · [Order V2](https://docs.kalshi.com/api-reference/orders/create-order-v2.md) · [Fixed point](https://docs.kalshi.com/getting_started/fixed_point_migration.md) · [Order book](https://docs.kalshi.com/getting_started/orderbook_responses.md)
