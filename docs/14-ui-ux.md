# UI and UX

Brazilian Portuguese workspaces for overview, terminal, backtests, history, event logs and operational administration. Show the exchange, execution mode, sync age and data provenance alongside financial values. A lime-accented market plot is the focal point, with a persistent execution control column and a compact collapsible navigation rail. Brand assets are original vectors. Typography uses a geometric display face and tabular financial data. Provide mobile adaptation, focus, loading, empty, risk blocked, stale and disconnected states, and reduced motion.
