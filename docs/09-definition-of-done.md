# Definition of Done

The Work Order requires an executable local application with secure login, admin route protection, verified API-driven controls, all six tested strategies, replay and paper settlement, official demo adapter contract tests, broker acceptance if credentials exist, exact accounting, incremental event continuity, central risk, hard demo confinement, migration and Compose smoke, dependency and secret scans, CI, evidence and a draft PR. Review residual defects before proposing any checkpoint promotion.

Evidence statuses: IMPLEMENTED, TESTED_WITH_MOCK, TESTED_WITH_REPLAY, TESTED_WITH_PAPER, TESTED_WITH_OFFICIAL_DEMO, NOT_TESTED and BLOCKED. A lower validation tier cannot prove a higher one.
